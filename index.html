About Me

Engineering, not just installing

Anyone can install a theme. I build the solution your business actually needs — from the database up.

I'm a Full-Stack WordPress and Shopify Developer who has spent the last 14+ years inside the web — writing PHP, shaping databases, wiring APIs and squeezing every millisecond out of page loads.

My work covers the complete development lifecycle: UI implementation, backend architecture, custom plugins and themes, REST API integrations, server configuration, security hardening and performance tuning. I don't hand off problems — I own them end to end.

What I enjoy most is the messy part: a business comes with a workflow that no off-the-shelf plugin can handle, and I get to design a clean, scalable system around it.

  • ✓Custom-first mindset — purpose-built code instead of plugin stacking.
  • ✓Performance obsessed — caching, query optimisation, Core Web Vitals.
  • ✓Security aware — sanitisation, hardening, API protection, backups.
  • ✓Clear communication — realistic timelines and honest updates.
